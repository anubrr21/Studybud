# StudyBud - Django Discord-like App

A Discord-inspired study discussion platform built using Django.

## Features
- Custom User Model
- User Authentication
- Create and Join Study Rooms
- Activity Feed
- User Profiles with Avatar Upload
- REST API Integration
- Responsive UI

## Tech Stack
- Python
- Django
- SQLite
- HTML/CSS
- JavaScript

## Setup Instructions

1. Clone the repository
2. Create virtual environment:
   python -m venv venv
3. Activate environment:
   venv\Scripts\activate
4. Install dependencies:
   pip install -r requirements.txt
5. Run migrations:
   python manage.py migrate
6. Start server:
   python manage.py runserver
